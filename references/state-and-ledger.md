# 状态、续跑、验收与回滚

移动收藏夹是**不可预览、不可撤销**的批量写操作。这份文档里每一条都是从真实事故里来的。

## 状态文件

全部在 `<wd>` 下：

| 文件 | 作用 |
|---|---|
| `snapshot.json` | 采集快照。**验收断言的基准** |
| `reclass_plan.json` | 判定结果（去向 / 理由 / 置信度） |
| `move_plan.json` | 机器读的移动方案（分批、目标夹 id） |
| `move_plan.md` | 人读的预演单，**确认凭据** |
| `apply_state.json` | 已完成清单 —— 续跑依据 |
| `apply_log.jsonl` | 每个成功批次的记录 —— **回滚的唯一依据** |
| `verify_report.json` | 验收结果 |
| `api_log.jsonl` | 请求日志（path / code / 耗时，不含凭据） |

## 幂等靠两层，缺一不可

1. **`apply_state.json`** 记录「目标夹 → 已移动的 key」，重跑时跳过。
2. **每次 `--run` 开头重新拉一次源夹的权威内容**，只移动「此刻还在源夹里」的条目。

第二层是关键：只有第一层的话，状态文件丢了、被手工删了、或者有人在两次运行之间手工挪过夹子，就会重复移动。加上第二层，重跑永远安全。

写状态文件的时机：**每批移动成功后立刻落盘**（原子写：写临时文件再 `replace`）。不要攒到最后统一写 —— 中途熔断就全丢了。

## 撞上风控怎么办

熔断发生时：

1. 立刻停止，**已完成的批次状态已落盘**；
2. 告诉用户「等 30 分钟以上再跑同一条命令」；
3. 用户重新跑时什么都不用改，脚本会自动只处理剩下的。

不要做的事：立刻重试、提高并发、调低间隔、换 IP 硬冲。风控是累加的，硬冲只会把冷却时间拉长。

## 预演单是必要的一道门

`plan_moves.py` 产出的 `move_plan.md` 要**真的交给人看**，包括：

- 逐条去向表（序号 / BV / 标题 / 去向 / 是否拿不准）；
- 需要新建的夹；
- **冲突清单**：已在别的夹、本次去向与之不同的条目（工具不自动去重，列出来由人决定）。

B站的移动操作没有确认框。脚本里一个方向写反，就是几百条错位。

## 验收断言

```bash
<python> scripts/apply_moves.py --workdir <wd> --verify
```

三条断言，任一不过就报错：

1. **源夹为空** —— 用 `ids` 接口查，不是 `list`（`list` 会少给数据，从而谎报「已空」）；
2. **覆盖数一致** —— 计划的条数 == 采集时源夹的权威条数。不等说明有计划外的条目，或漏了幽灵条目；
3. **各目标夹齐备** —— 每条计划里的条目都确实在它该在的目标夹里。

## 回滚

**先预览，再执行。**

```bash
<python> scripts/apply_moves.py --workdir <wd> --rollback        # 只预览影响面
<python> scripts/apply_moves.py --workdir <wd> --rollback --yes  # 真执行
```

原理：每次移动等价于「从 A 摘掉 + 加到 B」，所以反向做一次就回去了。回滚读 `apply_log.jsonl`，把成功批次按**倒序**反向移动。

**局限**（必须在执行前讲清楚）：

- 回滚记录的是**本工具动过的那些条目**；
- 如果有人在两次整理之间手工挪过夹子，无脑反向执行会**覆盖那些手动改动**；
- 因此回滚默认只预览，必须显式加 `--yes`。

回滚完成后会清空 `apply_state.json`，避免下次 `--run` 误以为已完成。

## 通用教训

**「文件已存在就跳过」的续跑保护，必须保证输入与产物一一对应。**

真实事故：转写脚本对同一支视频的多个分P复用同一个工作目录，第 2 个分P起命中「音频已下载」「转写结果已存在」的短路，于是把第 1 个分P的结果复制成了 N 份 —— 17 个文件字节数完全相同。没有报错，只是数据错了。

**最快的自检信号：批量产物的字节数是否雷同。** 本 skill 的移动流程同理 —— `apply_state.json` 的键必须细到「`目标夹 + 条目 key`」，不能只记「这个目标夹处理过了」。

**假成功是默认行为，不是异常。** 写完必回读（见 data-model.md）。凡是有批量写入的地方，都要问一句「我怎么知道它真的写进去了」。
